# Improvements

1. ROLE Organizer: Aumentar o leque de funcionalidades para o organizador do evento, permitindo que ele consiga editar eventos, deletar eventos, gerenciar ingressos vendido (ver quem comprou, quantos foram vendidos, etc).

2. ROLE Organizer: Cada Organizador deve ter acesso apenas aos eventos que ele criou, não podendo ver os eventos de outros organizadores (Na dúvida).

3. ROLE Customer: Aumentar o leque de funcionalidades para o cliente, site muito vazio para o cliente teria que ter mais funcionalidades, como por exemplo fazer comentários, avaliar o evento, conversar com outros clientes, etc.

4. ROLE Gatekeeper: Leque justo de funcionalidades para o porteiro, mas poderia ter certas restrições (Não sei bem ainda).

5. Duvidas de dominio: O domínio do sistema ainda não está muito claro, o que cada papel pode fazer, o que cada usuário pode fazer, etc. Isso precisa ser melhor definido.

6. Ampliação do uso do TMDB, para que o usuário consiga ver mais informações sobre o filme, como por exemplo elenco, trailer, etc.

7. Criação de outros tipos de eventos (Trabalhar com multi nichos: Cinema, Show, Esportes, etc).

Observção: No geral o sistema funciona bem, mas ainda está meio vazio. Eu ainda não sei muito bem o domínio do sistema, não qual tipo de regra de negócio ele deve ter, por exemplo:

1. Qualquer pessoa pode ser um organizador de evento? Sim, então seria site ideal para eventos independentes, por exemplo grupo de amigos que querem fazer algo e convidar outras pessoas.

2. Eventos são só pagos? Sim, então já elimina a possibilidade de eventos gratuitos (caridade, evento de amigos, etc).

3. Eventos apenas relacionados a filmes? Sim, então o sistema é voltado apenas para eventos de cinema, o que limita muito o público alvo do sistema.

4. Role Admin Meu Ingresso: Criação de admin geral do sistema completo. Talvez seja interessante ter um admin geral do sistema.

Ou seja, o sistema ainda tem muita coisa em aberto.
